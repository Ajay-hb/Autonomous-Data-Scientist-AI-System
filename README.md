# 📖 Overview

AutoDS AI is a next-generation autonomous data science platform designed to automate the complete machine learning workflow.

The platform enables users to:

- 📂 Upload datasets
- 🧹 Automatically clean data
- 📊 Perform exploratory data analysis
- 📈 Generate interactive visualizations
- 🤖 Train machine learning models
- ⚡ Optimize hyperparameters
- 🧠 Perform clustering analysis
- 📄 Generate downloadable PDF reports

---

# ✨ Core Features

| Feature | Description |
|---|---|
| 📂 Dataset Upload | Supports CSV & Excel files |
| 🧹 Automated Cleaning | Handles missing values & duplicates |
| 📊 EDA Dashboard | Interactive data analysis |
| 📈 Visual Analytics | Histograms, Heatmaps, Boxplots |
| 🤖 Machine Learning | Classification & Regression |
| ⚡ Hyperparameter Tuning | Optuna & GridSearchCV |
| 🧠 Clustering | KMeans & DBSCAN |
| 📄 PDF Reports | Downloadable analytics reports |
| 🎨 Premium UI | Animated AI dashboard |

# 🚀 How to Run Locally

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/autods-ai.git
```

## Navigate to Project Folder

```bash
cd autods-ai
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```
